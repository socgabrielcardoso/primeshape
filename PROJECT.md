# Project Profile

**PrimeShape** is a computer-vision study project that combines frontend interaction, backend processing and model-oriented components for visual experimentation.

## What this project demonstrates
- Multi-layer project organization
- Computer-vision experimentation
- Backend/frontend integration
- Automated testing with Pytest
- Local development tooling and repeatable execution

## Portfolio signal
This repository demonstrates the ability to organize an experimental vision system as a maintainable technical project rather than a single prototype script.

**Domain:** Computer Vision, Applied Software Engineering  
**Stack:** Python, Web Frontend, Pytest  
**Status:** Technical laboratory
