# Security Policy

## Scope

primeshape is maintained as a computer-vision study project. Security reports are welcome when they concern code or behavior that exists in this repository.

## Reporting a vulnerability

Please do not publish credentials, personal data, working exploit chains or other sensitive details in a public issue.

Prefer a private GitHub security report when that option is available. Otherwise, contact the repository owner through the GitHub profile and provide only the minimum information needed to establish a private reporting channel.

A useful report should include:

- affected component or file;
- reproducible steps;
- expected and observed behavior;
- security impact;
- suggested remediation, when available.

## Laboratory boundaries

Demonstrations, sample data and attack-like flows in this repository are intended for controlled study. They are not authorization to test third-party systems, accounts or infrastructure.

## Secrets

Do not commit API keys, passwords, tokens, private certificates or production data. If a secret is exposed, revoke or rotate it before removing it from the repository history.
